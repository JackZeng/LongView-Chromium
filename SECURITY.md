# Security policy

LongView inherits Chromium's security model only when built and updated responsibly. This repository does not provide Google Chrome services, signing, or an automatic security-update guarantee in v0.2.

For a suspected vulnerability in LongView-specific code, avoid publishing exploit details in a public issue. Contact the repository owner privately through the GitHub account profile and include the affected commit, reproduction, impact, and suggested mitigation.

For vulnerabilities in upstream Chromium, follow the Chromium project's security reporting process.

Do not use an old LongView development build as a daily browser after its pinned Chromium version stops receiving security fixes. Rebase to a current supported Chromium release before distribution.
